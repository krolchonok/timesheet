# Timesheet

Веб-таблица учёта задач и часов для экспорта в MS Project.

## Возможности

- Роли **user** и **admin**
- Недельные табели, категории задач, статусы (новая / редактируется / перенесено)
- Админ: просмотр заполнения (40 ч), перенос итогового названия, управление сотрудниками и категориями
- Экспорт CSV

## Запуск

```bash
pip install -r requirements.txt
./start.sh 8888
```

Открыть: http://127.0.0.1:8888/login

## Демо-доступ

| Логин | Пароль | Роль |
|-------|--------|------|
| `user` | `user` | пользователь |
| `admin` | `admin` | администратор |

Для production задайте `SECRET_KEY` в окружении.

## Стек

Flask + SQLite, статический фронтенд (HTML/JS/CSS).
